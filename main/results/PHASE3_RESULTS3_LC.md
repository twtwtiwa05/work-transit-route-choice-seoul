# Phase 3 Results: Latent Class Logit Model with Concomitant Variables

추정 완료: 2026-02-08

---

## 1. 개요

### 1.1 연구 목적

Mixed Logit이 **연속 분포**로 이질성을 포착하는 반면, Latent Class Model은 **이산적 행태 군집**을 데이터 기반으로 발견한다. 본 연구는 Greene & Hensher (2003)의 **concomitant variable** 프레임워크를 적용하여, 관측 가능한 이용자 특성(카드유형, 첨두여부)이 잠재 클래스 소속 확률에 미치는 영향을 동시 추정한다.

### 1.2 모형 사양

**효용함수 (class-specific):**
```
V_j|c = β_ride,c × T_ride + β_walk,c × T_walk + β_transfer,c × N_transfer + β_subway,c × D_subway
```

Peak 교호작용은 Mixed Logit에서 비유의(p>0.3)로 확인되어 제외하였다.

**클래스 멤버십 함수 (concomitant variables):**
```
π_c(n) = exp(γ_c + δ_c' × Z_n) / Σ_k exp(γ_k + δ_k' × Z_n)

Z_n = [D_children, D_youth, D_elderly, D_disabled, D_peak]
```

마지막 클래스(K)를 기준 클래스로 설정 (γ_K = 0, δ_K = 0).

### 1.3 추정 설정

| 항목 | 값 |
|------|-----|
| 효용 변수 | T_ride, T_walk, N_transfer, D_subway (4개) |
| 멤버십 공변량 | D_children, D_youth, D_elderly, D_disabled, D_peak (5개) |
| 탐색 K 범위 | 2, 3, 4, 5 |
| 랜덤 시작점 | 10회/K |
| 최적화 | L-BFGS-B (해석적 그래디언트) |
| 수렴 기준 | FTOL = 1e-8, MAX_ITER = 1,000 |
| 파라미터 제약 | β ∈ [-10, +10], 멤버십 ∈ [-5, +5] |
| 표본 | 50,000 체인 (층화 추출) |
| 초기값 | MNL 추정치 기반 + 무작위 교란 |

### 1.4 v1 → v2 주요 변경

| 항목 | v1 | v2 (본 결과) |
|------|-----|-------------|
| 클래스 멤버십 | 상수 π (모든 개인 동일) | **공변량 함수** π_c(Z_n) |
| 효용 변수 | 6개 (Peak 교호작용 포함) | **4개** (핵심 변수만) |
| 최적 K | 2 (비유의적 교차분석) | **3 (χ²=46,861***)** |

## 3. 최적 모형 파라미터 (K = 3)

### 3.1 클래스 멤버십 계수

기준 클래스: Class 3. 계수는 Class 3 대비 해당 클래스에 소속될 **상대적 로그 오즈(log-odds)**를 의미한다.

| 공변량 | Class 1 (δ) | SE | t-stat | Class 2 (δ) | SE | t-stat |
|--------|------------|------|--------|------------|------|--------|
| Intercept | -1.536*** | 0.422 | -3.64 | +1.734*** | 0.115 | 15.03 |
| D_children | +1.544 | 0.968 | 1.59 | -0.517 | 0.468 | -1.11 |
| D_youth | +1.404† | 0.743 | 1.89 | -0.133 | 0.301 | -0.44 |
| **D_elderly** | **+3.091***** | **0.510** | **6.06** | **-1.067**** | **0.340** | **-3.14** |
| **D_disabled** | **+1.952***** | **0.543** | **3.59** | **-0.680*** | **0.333** | **-2.04** |
| D_peak | +0.017 | 0.371 | 0.05 | +0.181 | 0.137 | 1.33 |

유의수준: *** p<0.001, ** p<0.01, * p<0.05, † p<0.10

**핵심 발견:**
1. **D_elderly → Class 1**: δ = +3.09*** — 고령자가 접근성 우선 클래스에 속할 로그오즈가 3.09 높음 (오즈비 = exp(3.09) = **22.0배**)
2. **D_disabled → Class 1**: δ = +1.95*** — 장애인의 오즈비 = exp(1.95) = **7.0배**
3. **D_elderly → Class 2**: δ = -1.07** — 고령자가 일반 클래스에 속할 확률 감소 (오즈비 = 0.34, 즉 66% 감소)
4. **D_peak**: 모든 클래스에서 비유의 → 첨두여부는 행태 군집 소속에 영향 없음 (ML 결과와 일관)

## 4. 클래스 프로파일 심층 분석

### 4.1 Class 1: 접근성 우선 이용자 (Accessibility-Priority Travelers, 8.7%)

**구성**: 고령자 61%, 장애인 28%, 일반 3%

| 특성 | 값 | 해석 |
|------|-----|------|
| β_ride = **+0.252** | 양의 값 | 차내시간이 길어도 선호 — 좌석 확보, 쾌적성, 접근성 등 비시간 편익 반영 |
| β_walk = -1.123 | MNL(-0.72)의 1.6배 | 보행 민감도 중간~높음 |
| β_transfer = **-10.0** | 경계값 | 환승을 거의 절대적으로 기피 → **사실상 사전적 선호(lexicographic)** |
| β_subway = **+8.12** | 매우 높음 | 지하철을 압도적으로 선호 |

**행태 해석**: 이 클래스는 "**환승 없는 지하철 직통 경로**"를 최우선으로 선택한다. 차내시간이 길어지더라도 환승이 없고 지하철을 이용할 수 있는 경로를 선호한다. β_ride의 양의 값은 차내시간 자체를 선호한다기보다, 지하철 좌석에 앉아 이동하는 것의 편익(좌석, 냉난방, 안전성)이 시간 비용을 상쇄함을 의미한다.

**Mixed Logit 대응**: ML 고령자 모형 (β_ride=+0.144, μ_transfer=-6.087, μ_subway=+5.632)과 방향이 일치하며, LC가 이를 더 극단적으로 분리함.

### 4.2 Class 2: 일반 이용자 (Mainstream Travelers, 77.2%)

**구성**: 일반 83%, 청소년 73%, 어린이 63%, 장애인 53%, 고령자 26%

| 특성 | 값 | 해석 |
|------|-----|------|
| β_ride = -0.077 | 음의 값 | 표준적 시간 가치 — 차내시간 최소화 |
| β_walk = -0.730 | MNL과 유사 | 보행 가중치 = |0.730/0.077| = **9.5배** |
| β_transfer = -3.272 | 합리적 수준 | 환승 페널티 = |3.272/0.077| = **42.5분** |
| β_subway = +2.022 | 양의 선호 | 지하철 보너스 = |2.022/0.077| = **26.3분** |

**행태 해석**: 전체 이용자의 77%를 차지하는 주류 집단으로, MNL의 pooled 추정치와 거의 동일한 합리적 경로선택 패턴을 보인다. 보행 1분은 차내시간 9.5분에 해당하고, 환승 1회는 차내시간 42.5분의 페널티를 가진다.

**Mixed Logit 대응**: ML pooled (β_ride=-0.034, μ_walk=-0.860, μ_transfer=-3.614, μ_subway=+2.585) 및 ML 일반 모형 (β_ride=-0.043)과 방향·크기가 유사.

### 4.3 Class 3: 극단적 지하철 충성자 (Extreme Subway Loyalists, 14.0%)

**구성**: 인구학적으로 분산 — 특정 카드유형에 편중되지 않음

| 특성 | 값 | 해석 |
|------|-----|------|
| β_ride = **+1.166** | 강한 양의 값 | 차내시간 증가를 강하게 선호 |
| β_walk = **-10.0** | 경계값 | 보행을 극단적으로 기피 |
| β_transfer = **-10.0** | 경계값 | 환승을 극단적으로 기피 |
| β_subway = **+10.0** | 경계값 | 지하철만 선택 |

**행태 해석**: 모든 파라미터가 극단값을 보이는 클래스로, "지하철 직통 + 보행 최소 + 환승 무(無)"인 경로만을 선택한다. Hard assignment는 165명(0.3%)에 불과하나 soft weight는 14%로, 이 클래스는 **독립적 집단이라기보다 Class 2 분포의 극단적 꼬리(tail)**에 해당한다. Mixed Logit의 연속 분포에서 β_walk과 β_transfer가 극단값을 가지는 개인들을 이산적으로 포착한 것이다.

**Mixed Logit 대응**: ML의 랜덤 파라미터 분포에서 95% 신뢰구간의 양 끝단에 해당. ML에서 σ_transfer=0.777이므로 μ±2σ ≈ [-3.6±1.6] = [-5.2, -2.0] 범위에 있으나, LC는 이를 [-10] 점으로 이산 근사한다.

## 6. 교차분석: 잠재 클래스 × 카드유형

### 6.3 연관성 검정

| 지표 | v1 (공변량 없음) | **v2 (공변량 포함)** |
|------|-----------------|-------------------|
| χ² | 4.01 | **46,860.71** |
| df | 4 | 8 |
| p-value | 0.404 | **< 0.001** |
| Cramér's V | 0.009 | **0.685** |

### 6.4 교차분석 해석

1. **고령자의 이중 행태**: 61%가 접근성 클래스에 속하지만, **26%는 여전히 일반 클래스**에 속한다. 이는 ML에서 발견된 고령자 내 이질성(σ_transfer=2.517)과 일관되며, "모든 고령자가 동일하지 않다"는 핵심 발견을 재확인한다.

2. **장애인의 분산 소속**: 54%가 일반, 28%가 접근성, 18%가 극단 클래스에 분산되어, 장애인 집단 내에서도 행태적 다양성이 크다.

3. **카드유형 ≠ 행태 클래스**: Cramér's V=0.685는 "강한 연관"이지만 1.0이 아니다. 행정적 카드유형 분류와 데이터 기반 행태 군집은 **연관되어 있으나 동일하지 않다** — 두 분류 체계가 상호 보완적임을 입증한다.

4. **Class 3의 인구학적 비특이성**: 극단적 행태 클래스가 특정 카드유형에 편중되지 않고 분산되어, 이 행태 패턴이 인구학적 특성이 아닌 **개인적 선호 차이**에 기인함을 시사한다.

### 8.2 경로안내 시스템 개선 방안

1. **카드유형 기반 초기 추천**: 고령자 카드 → 접근성 클래스(61% 확률)의 파라미터로 경로 추천. 단, 26%가 일반 클래스이므로 대안 경로도 제시.
2. **학습 기반 개인화**: 이용 이력에서 사후 확률을 갱신하여 개인별 클래스 소속을 정밀화.
3. **장애인 맞춤 안내**: 장애인의 28%가 접근성 클래스 — 무장애 환승 시설 정보와 환승 최소화 경로를 우선 표시.

### 8.3 교통 계획 시사점

- **고령자 직통 노선 수요**: 고령자의 61%가 환승을 극단적으로 기피 → 고령 인구 밀집 지역에서 환승 없는 직통 노선의 수요가 높음
- **환승 시설 투자 우선순위**: 접근성 클래스가 8.7%이므로, 환승 시설 개선의 주요 수혜 대상은 명확하게 고령자·장애인
- **일반 이용자 보행 환경**: 77%의 일반 클래스는 보행 가중치가 9.5×이므로, 역 접근 보행 거리 단축이 가장 효과적인 개선

## 9. 결론

### 9.1 학술적 기여

1. **공변량 멤버십의 효과 실증**: 공변량 없는 LC(v1)에서는 교차분석이 비유의(χ²=4.01, p=0.40)였으나, 공변량 추가(v2)로 χ²=46,861(p<0.001)로 극적 개선. 이는 concomitant variable이 잠재 클래스의 인구학적 기반을 식별하는 데 필수적임을 입증.

2. **ML-LC 교차 타당성**: Mixed Logit(연속 분포)과 Latent Class(이산 군집)가 독립적으로 동일한 이질성 구조를 포착. 고령자의 양의 β_ride, 극단적 환승 기피, 지하철 강선호가 두 모형에서 모두 확인됨.

3. **카드유형 ≠ 행태 클래스**: 데이터 기반 잠재 클래스와 행정적 카드유형은 강한 연관(V=0.685)을 보이지만 동일하지 않음. 같은 고령자라도 61%만 접근성 클래스에 속하고 26%는 일반 클래스 — **집단 내 이질성(within-group heterogeneity)**을 실증.

4. **Peak 효과 부재 재확인**: MNL, ML, LC 세 모형 모두에서 Peak 효과가 비유의. 서울 대중교통 이용자의 경로선택 행태는 첨두/비첨두 시간대에 따라 구조적으로 달라지지 않음.

### 9.2 한계

1. **경계값 적중**: Class 1(N_transfer)과 Class 3(T_walk, N_transfer, D_subway)에서 β가 ±10 경계에 도달. SE가 존재하고 t-stat이 유의하므로 통계적으로는 유효하나, 추정치가 "잘린 값"일 가능성이 있음. 이는 해당 클래스의 선호가 **사전적(lexicographic)**에 가까움을 시사.

2. **Class 3 해석**: Hard assignment 165명(0.3%) vs Soft weight 14%의 괴리는, 이 클래스가 독립적 집단이 아닌 연속 분포의 이산 근사임을 시사. 엄밀히는 3-class가 아닌 "2-class + tail"로 해석하는 것이 적절할 수 있음.

3. **표본**: 50,000 체인 층화 추출 사용. 전체 329K 체인 대비 15%이나, MNL 대비 ρ²와 Hit Rate 개선이 일관되어 대표성에 문제 없음.
