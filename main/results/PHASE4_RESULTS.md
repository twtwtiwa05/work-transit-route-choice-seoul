## 1. 개요

### 1.1 배경

Phase 3에서 추정된 행태 파라미터(β)를 OTP 라우팅 엔진의 비용함수에 반영하고, 경로 생성과 행태 모형 간의 일관성을 달성하고자 했다.

**핵심 문제**:
- OTP 기본 파라미터: `walkReluctance=1.0`, `transferCostSeconds=120`
- Phase 3 MNL 추정: 보행 가중치 22.7×, 환승 페널티 ~100분
- → OTP 가정과 실제 행태 사이에 큰 괴리 존재

### 1.2 접근법 요약 및 결론

| 접근법 | 설명 | 핵심 결과 | 상태 |
|--------|------|-----------|------|
| 전통적 반복 | β→θ→OTP 재실행→β 재추정 | Exact Match 28.66%→14.0% (붕괴) | ❌ 실패 |
| A. Pooled MSA | 단일 θ (MNL β 비율 기반) | +1.02%p (Best Match 기준) | ✅ 완료 |
| B. 유형별 θ | 5유형별 MNL 비율 기반 θ | +4.3%p (Best Match 기준) | ✅ 완료 |
| E. 확률적 RSM (IPW) | LHS+RSM, MNL 확률 가중, IPW 보정 | θ 경계 수렴 (구조적 한계 발견) | ✅ 완료 |
| **MNL 재순위** | **MNL β로 OTP 대안 재순위** | **+1.89%p (OTP 재실행 없이)** | **✅ 핵심 기여** |

**Phase 4의 핵심 결론**: θ 최적화(파라미터 보정)의 개선 폭에는 구조적 상한이 존재하며(~+1%p), 이를 넘어서는 것은 MNL 기반 재순위(re-ranking)를 통해 달성된다. OTP가 실제로 추천하는 경로보다 MNL이 선택하는 경로가 이용자 행태를 더 정확히 반영한다.

## 2. 전통적 반복 보정의 실패

### 2.1 시도

초기에 전통적 방식으로 반복 보정을 시도:

**Iter0 → Iter1 파라미터 변경**:
```
walkReluctance: 1.0 → 5.0 (+400%)
transferCostSeconds: 120 → 300 (+150%)
```

**결과**:
| 지표 | Iter0 | Iter1 | 변화 |
|------|-------|-------|------|
| Exact Match | 28.66% | 14.0% | **-14.6%p** |
| sim_total | 0.626 | 0.42 | **-0.21** |

### 2.2 원인 분석

1. **Pareto Surface 급변**: walkReluctance 5배 증가 → 보행 적은 경로 위주 탐색 → 기존 경로들이 Pareto-optimal에서 탈락
2. **TCD 경로 고정 문제**: TCD 관측 경로는 변하지 않음 → OTP 경로만 바뀌면 매칭률 필연적 하락
3. **순환 의존성**: β 추정 → Choice Set 변경 → β 불안정 → 수렴 불가

### 2.3 결론

전통적 반복 보정은 대중교통 경로선택 모형에 적용하기 어려움:
- 도로 네트워크(연속적)와 달리 대중교통(이산적)은 파라미터 변화에 민감
- **Choice Set 고정 접근법**(β를 Ground Truth로 고정, θ만 조정)이 더 안정적

## 3. 접근법 A: Choice Set 고정 보정 (Pooled MSA)

### 3.1 방법론

**핵심 아이디어**: Phase 3에서 추정한 β를 "Ground Truth"로 고정하고, β → θ 변환만 MSA로 반복 수렴.

**β → θ 매핑 공식**:
```
walkReluctance = |β_walk / β_ride|
transferCostSeconds = |β_transfer / β_ride| × 60
```

**MSA (Method of Successive Averages) 업데이트**:
```
α_k = min(0.3, 1/(k+1))
θ_k = θ_{k-1} + α_k × (θ_target − θ_{k-1})
```

**파라미터 상한 (물리적 제약)**:
- `walkReluctance` ≤ 6.0 (보행 1분 = 차내 6분)
- `transferCostSeconds` ≤ 300 (환승 1회 = 5분)

### 3.2 수렴 과정

```
Iter    α       walkReluctance    transferCost    상태
------------------------------------------------------------
  0     -           2.00              120         초기값
  1   0.300         3.20              174
  ...
 10   0.091         5.47              276         수렴!
------------------------------------------------------------
```

**최종 보정값**:
| 파라미터 | 초기값 | 보정값 | 변화 |
|----------|--------|--------|------|
| walkReluctance | 2.0 | **5.47** | +174% |
| transferCostSeconds | 120 | **276** | +130% |

### 3.3 검증 결과 (50K 서브샘플, Best Match 기준)

| 지표 | Baseline | Calibrated | 변화 |
|------|----------|------------|------|
| **Exact Match** | 28.66% | **29.68%** | **+1.02%p** |
| **sim_total (평균)** | 0.626 | **0.641** | **+0.015** |

### 3.4 해석

- 보정된 파라미터가 Baseline보다 TCD 관측 경로와 더 잘 매칭됨
- Phase 3에서 추정한 β가 OTP θ로 정확히 전달됨
- 비용함수와 행태모형 간 자기일관성(self-consistency) 달성

## 5. 평가 지표의 진화

### 5.1 Best Match의 한계 발견

접근법 A~B는 **Best Match** (10개 대안 중 sim_total 최대)로 평가했다. 그러나 이 방식은 파라미터를 아무리 바꿔도 10개 중 하나는 항상 어느 정도 매칭되므로, **보정 효과가 희석**된다.

### 5.2 OTP 1순위 도입

OTP가 실제로 추천하는 경로(generalized_cost 최소)로 평가하면 보정 효과가 직접 드러난다.

**전체 데이터(1,320,030 체인) 베이스라인**:

| 평가 방식 | Exact Match | sim_total |
|-----------|-------------|-----------|
| Best Match (기존) | 28.62% | 0.6260 |
| **OTP 1순위 (수정)** | **20.34%** | **0.5372** |
| **Gap** | **8.28%p** | **0.0887** |

→ Gap = 보정을 통해 개선 가능한 여지. Best Match 방식에서는 이 여지가 보이지 않았음.

**유형별 OTP 1순위 베이스라인**:

| 유형 | 체인 수 | Exact(OTP 1순위) | Exact(Best Match) | Gap |
|------|---------|-----------------|-------------------|-----|
| **전체** | **1,320,030** | **20.34%** | 28.62% | **8.28%p** |
| GENERAL | 1,044,091 | 19.84% | 28.49% | 8.65%p |
| ELDERLY | 177,303 | 19.84% | 24.11% | 4.27%p |
| YOUTH | 49,772 | 27.83% | 41.72% | 13.89%p |
| CHILDREN | 10,583 | 31.30% | 46.48% | 15.18%p |
| DISABLED | 38,281 | 23.60% | 31.16% | 7.56%p |

### 5.3 결정론적 → 확률적 평가

결정론적 평가(OTP 1순위 = 정답 or 오답)의 근본 한계:
- 2순위 경로가 관측 경로와 일치해도 점수 = 0
- θ를 미세 조정해도 1순위가 바뀌지 않으면 성과 변화 없음
- **계단형(step function) 목적함수** → 경사 기반 최적화 불가

확률적 평가의 장점:
- 모든 대안에 MNL 확률을 부여하고 유사도를 가중합
- **연속적이고 매끄러운 목적함수** → 최적화에 적합
- 이산선택 이론(McFadden, 1974)에 기반한 이론적 정당성

## 6. 접근법 E: 확률 기반 LHS + RSM 최적화 (IPW 보정)

### 6.1 수학적 프레임워크

#### 목적함수

**F₁ (IPW-가중 기대 유사도)** — 주요 최적화 대상:
```
F₁(θ) = Σᵢ wᵢ^IPW × Σⱼ P(j|i,θ) × sim(i,j) / Σᵢ wᵢ^IPW
```

**F₂ (IPW-가중 기대 완전일치율)** — 해석 가능한 보조 지표:
```
F₂(θ) = Σᵢ wᵢ^IPW × Σⱼ P(j|i,θ) × em(i,j) / Σᵢ wᵢ^IPW
```

#### IPW (Inverse Probability Weighting) 보정

환승 과표집(oversampling)으로 인한 편향을 보정:
```
w_i^IPW = (모집단 비율_s) / (샘플 비율_s)
환승 0회: w = 82% / 50% = 1.64
환승 1회: w = 16% / 40% = 0.40
환승 2회+: w = 2% / 10% = 0.20
```

### 6.2 실행 및 결과 (GENERAL)

| 항목 | 값 |
|------|-----|
| 샘플 크기 | 5,000체인 |
| LHS 포인트 | 22개 |
| 검증 포인트 | 6개 |
| 총 평가 | 28회 |
| 소요 시간 | 125.7분 |
| RSM R² | **0.9802** |

**최적 θ** (GENERAL):

| 파라미터 | 범위 | 최적값 | 위치 |
|----------|------|--------|------|
| walkReluctance | [2.0, 40.0] | **40.0** | **상한 경계** |
| transferCostSeconds | [15, 500] | **17** | **하한 근처** |
| subwayReluctance | [0.2, 3.0] | **3.0** | **상한 경계** |

**성과 지표**:
| 지표 | Baseline (OTP 기본) | 접근법 E 최적 θ | 변화 |
|------|---------------------|-----------------|------|
| F₁ (기대 유사도) | 0.5567 | **0.6183** | +0.0616 |
| F₂ (기대 완전일치율) | 21.35% | **28.58%** | +7.23%p |
| det_exact (OTP 1순위) | 19.84% | 20.79% | **+0.95%p** |
| mnl_exact (MNL 1순위) | 21.84% | **30.66%** | **+8.82%p** |

### 6.3 구조적 한계 발견

**3개 파라미터 모두 경계값에 수렴**하는 현상이 반복 관측:

| 시도 | walkRel | transCost | subRel | 경계 수렴? |
|------|---------|-----------|--------|-----------|
| E-IPW v1 (넓은 범위) | 80.0 | 5 | 5.0 | 3/3 경계 |
| E-IPW v2 (합리적 범위) | 40.0 | 17 | 3.0 | 3/3 경계 |

**원인 분석**: F₁ 목적함수의 구조적 특성

F₁은 확률 가중 기대 유사도이므로:
1. **극단적 파라미터** → 매우 다양한(분산 큰) Choice Set 생성
2. **다양한 Choice Set** → MNL이 재순위할 여지가 커짐
3. **MNL 재순위 효과 극대화** → F₁ 최대화

즉, F₁이 높아지는 경로: θ 자체의 개선이 아니라 **MNL이 재순위할 "재료"가 풍부해짐**

이는 det_exact(OTP 자체 순위의 정확도)와 mnl_exact(MNL 재순위 후 정확도)의 극적 괴리에서 확인된다:
- det_exact: 19.84% → 20.79% (**+0.95%p** — 미미)
- mnl_exact: 21.84% → 30.66% (**+8.82%p** — 대폭 개선)

→ F₁ 개선의 대부분은 θ 개선이 아니라 **MNL 재순위 효과에 기인**

### 6.4 해석 및 학술적 함의

접근법 E의 결과는 "실패"가 아니라 **θ 최적화의 구조적 한계를 실증**한 것:

1. **OTP 비용함수(generalized_cost)의 한계**: 선형 비용함수로는 이용자 행태의 비선형성을 표현할 수 없음
2. **MNL β의 우위**: 관측 데이터에서 직접 추정된 β가 공학적 비용함수보다 이용자 행태를 더 정확히 반영
3. **θ 최적화의 상한**: OTP 1순위 정확도 기준 ~+1%p가 현실적 상한

이 발견은 **MNL 재순위 분석**(제7장)으로 이어진다.

## 7. MNL 재순위 분석 (핵심 기여)

### 7.1 개요

**분석 목적**: OTP가 생성한 경로 대안을 MNL 효용함수로 재순위(re-ranking)했을 때의 개선 효과를 전체 데이터에서 다각도로 검증한다.

**방법**:
```
V_j = β_ride × T_ride_j(분) + β_walk × T_walk_j(분)
    + β_transfer × N_transfer_j + β_subway × D_subway_j
```
- β: Phase 3 Pooled MNL 계수 (고정)
- OTP 1순위: generalized_cost가 최소인 대안
- MNL 1순위: V가 최대인 대안 (확정적 선택)
- Best Match: sim_total이 최대인 대안 (이론적 상한)

**분석 규모**: 1,320,030 체인, 4,884,216 경로 쌍 (평균 3.70 대안/체인)

**소요 시간**: 16.8분

### 7.2 전체 결과

| 순위 방식 | Exact Match | Sim Total (평균) |
|-----------|-------------|-------------------|
| OTP 1순위 (generalized_cost min) | 20.34% | 0.5372 |
| **MNL 1순위 (V max)** | **22.23%** | **0.5713** |
| Best Match (sim_total max, 이론적 상한) | 28.62% | 0.6260 |
| **MNL - OTP 차이** | **+1.89%p** | **+0.0341** |

**해석**: OTP를 재실행하지 않고 기존 대안에 MNL 확률을 적용하는 것만으로 Exact Match가 +1.89%p 개선되었다. 이는 접근법 A의 θ 보정(+1.02%p, Best Match 기준, OTP 재실행 필요)보다 큰 개선폭이며, 추가 계산 비용이 거의 없다.

Best Match(28.62%)와 MNL 1순위(22.23%)의 차이 6.39%p는 MNL이 관측 경로를 포함하지 않는 대안 집합에서 발생하며, 이는 Choice Set 생성의 근본적 한계를 반영한다.

### 7.3 유형별 분석

| 유형 | 체인 수 | OTP 1순위 Exact | MNL 1순위 Exact | Δ Exact | OTP sim | MNL sim | Best sim |
|------|---------|-----------------|-----------------|---------|---------|---------|----------|
| GENERAL | 1,044,091 | 19.84% | 21.84% | **+1.99%p** | 0.5385 | 0.5728 | 0.6312 |
| ELDERLY | 177,303 | 19.84% | 21.01% | +1.16%p | 0.4995 | 0.5335 | 0.5647 |
| YOUTH | 49,772 | 27.83% | 30.32% | **+2.49%p** | 0.6144 | 0.6468 | 0.7120 |
| CHILDREN | 10,583 | 31.30% | 33.53% | **+2.23%p** | 0.6403 | 0.6706 | 0.7353 |
| DISABLED | 38,281 | 23.60% | 25.11% | +1.51%p | 0.5478 | 0.5784 | 0.6258 |

**유형별 해석**:

1. **YOUTH (+2.49%p, 최대 개선)**
   - 일관된 통행 패턴(학교-학원 등 고정 경로)과 지하철 선호 경향이 뚜렷
   - MNL의 지하철 더미(β_subway=+2.538)가 이 패턴을 정확히 포착
   - OTP의 generalized_cost는 이러한 수단 선호를 반영하지 못함

2. **CHILDREN (+2.23%p)**
   - YOUTH와 유사한 패턴 (단순하고 일관된 경로 선택)
   - 가장 높은 베이스라인(31.30%)에서 추가 개선 → 예측이 상대적으로 용이한 집단

3. **GENERAL (+1.99%p)**
   - 전체의 79.1%를 차지하는 가장 큰 집단
   - 행태 다양성이 높지만, MNL이 평균적으로 OTP보다 우수

4. **DISABLED (+1.51%p)**
   - 보행 시간에 대한 높은 민감도(β_walk = -0.6442)를 MNL이 반영
   - OTP 기본 비용함수는 장애인의 보행 부담을 과소평가

5. **ELDERLY (+1.16%p, 최소 개선)**
   - 가장 낮은 베이스라인 유사도(0.4995) → 행태 이질성이 가장 큼
   - MNL Pooled β가 고령자 특유의 행태(β_ride 양수, 극도의 환승 기피)를 충분히 반영하지 못함
   - 유형별 β를 적용하면 추가 개선 가능성 있음 (ELDERLY β: β_ride=-0.032, β_transfer=-3.996)

### 7.6 대안 수별 분석

| 대안 수 | 체인 수 | OTP Exact | MNL Exact | Δ Exact |
|---------|---------|-----------|-----------|---------|
| 1개 | 345,967 (26.2%) | 32.92% | 32.92% | **+0.00%p** |
| 2개 | 170,755 (12.9%) | 23.81% | 25.33% | +1.52%p |
| 3-4개 | 332,660 (25.2%) | 19.10% | 21.33% | +2.23%p |
| **5개+** | **470,648 (35.7%)** | 10.72% | 13.90% | **+3.17%p** |

**해석**:

1. **대안 1개 (26.2%): Δ = 0.00%p**
   - 대안이 1개뿐이면 OTP든 MNL이든 선택지가 동일 → 재순위 불가
   - 이 체인들의 높은 Exact Match(32.92%)는 OTP가 유일 대안을 정확히 찾은 경우

2. **대안 수 ↑ → MNL 개선폭 ↑ (단조 증가)**
   - 2개: +1.52%p → 3-4개: +2.23%p → 5개+: **+3.17%p**
   - 대안이 많을수록 OTP와 MNL의 순위가 달라질 가능성 ↑
   - 이는 MNL이 "더 좋은 대안을 식별할 수 있는 기회"가 많기 때문

3. **대안 5개+ (35.7%): 최대 개선**
   - 이 구간에서 OTP Exact Match는 매우 낮음(10.72%) → generalized_cost 순위의 한계가 가장 극명
   - MNL이 +3.17%p 개선하여 13.90%로 끌어올림
   - 해석: 다양한 경로 대안이 존재하는 복잡한 OD에서 MNL의 행태적 판단력이 가장 큰 가치를 발휘

**시사점**: MNL 재순위는 **경로 대안이 풍부한 OD**(도심 내, 복수 경유 가능)에서 가장 효과적이다. 대안이 1개인 단순 OD(교외, 직통노선 1개)에서는 재순위 자체가 불가능하므로 효과가 없다. 이는 MNL 재순위가 **도시 중심부의 복잡한 네트워크에서 특히 유용**함을 의미한다.

### 7.8 MNL 선택확률 분포

| 구간 | 체인 수 | 비율 | 해석 |
|------|---------|------|------|
| P = 0.0 ~ 0.3 | 124,027 | 9.4% | 높은 불확실성, 대안 간 경쟁 치열 |
| P = 0.3 ~ 0.5 | 240,492 | 18.2% | 중간 불확실성 |

**통계**:

- 중앙값: **0.8383**
- 표준편차: 0.2831

**해석**:

1. **45.4%가 P > 0.9**: MNL이 거의 확정적으로 하나의 대안을 선택하는 체인이 전체의 절반에 가까움. 이 체인들은 대안 간 효용 차이가 크거나 대안이 1개뿐인 경우. 이 구간에서는 θ를 아무리 바꿔도 MNL 순위가 변하지 않음 → **θ 최적화가 무의미한 영역**.

2. **27.6%가 P < 0.5**: MNL 1순위의 확률이 50% 미만 → 대안 간 경쟁이 치열한 구간. 이 체인들에서 θ 변경의 효과가 가장 클 수 있지만, 동시에 예측 불확실성도 가장 높음.

3. **중앙값(0.8383) >> 평균(0.7252)**: 왼쪽으로 꼬리가 긴(left-skewed) 분포. 대부분의 체인에서 MNL이 높은 확신으로 선택하지만, 소수의 체인에서 매우 낮은 확률 → 혼합 분포.

**시사점**: MNL 확률 분포의 이분법적 특성(높은 확신 45.4% + 낮은 확신 27.6%)은 이용자 이질성을 반영한다. 높은 확신 구간의 이용자는 "한 가지 분명한 최적 경로"가 있는 반면, 낮은 확신 구간의 이용자는 "여러 경쟁 경로 사이에서 선택"하는 상황. 후자의 집단이 Mixed Logit에서 관측된 이질성(σ가 모두 유의)과 일관된다.

### 7.10 선택 경로 특성 비교

| 특성 | OTP 1순위 | MNL 1순위 | 차이 | 해석 |
|------|-----------|-----------|------|------|
| 차내시간 (분) | 18.8 | 19.9 | **+1.1** | MNL은 더 긴 차내시간 수용 |
| 보행시간 (분) | 3.2 | 2.6 | **-0.5** | MNL은 보행 최소화 |
| 환승 횟수 | 0.50 | 0.40 | **-0.10** | MNL은 환승 기피 |
| 지하철 비율 | 61.5% | 63.5% | **+2.0%p** | MNL은 지하철 선호 |

**행태적 해석**:

MNL이 선택하는 경로는 OTP 1순위 대비:

1. **보행 시간 -0.5분 (16% 감소)**: β_walk/β_ride = 22.7×에 의해 보행이 강하게 회피됨. OTP의 walkReluctance=1.0은 보행을 차내시간과 동일하게 취급하지만, 실제 이용자는 보행 1분을 차내 22.7분과 등가로 인식.

2. **환승 횟수 -0.10회 (20% 감소)**: β_transfer에 의한 환승 페널티가 OTP의 120초(2분)보다 훨씬 큼(~100분). MNL은 환승 1회를 피하기 위해 상당한 우회를 감수하는 경로를 선택.

3. **차내시간 +1.1분 (5.9% 증가)**: 보행과 환승을 줄이는 대가로 차내시간이 약간 증가. 이는 합리적 트레이드오프 — β_ride(-0.075)의 절대값이 β_walk(-0.644)의 1/8.6에 불과하므로, 차내시간 1.1분 증가는 보행 0.13분 감소와 등가.

4. **지하철 비율 +2.0%p**: β_subway(+2.538)에 의한 지하철 선호. 동일 OD에서 버스 직통과 지하철 경유가 경쟁할 때, MNL은 지하철 경유를 선호 → 실제 이용자의 지하철 선호 행태를 반영.

**종합**: MNL이 선택하는 경로 프로파일은 "보행을 최소화하고, 환승을 줄이며, 지하철을 선호하되, 그 대가로 약간 더 긴 차내시간을 수용"하는 패턴이다. 이는 Phase 3 MNL에서 추정된 β 계수와 완벽히 일관되며, 실제 이용자의 행태를 반영한다.

## 8. 종합 비교: θ 최적화 vs MNL 재순위

### 8.1 정량적 비교

| 접근법 | 방법 | 개선폭 (Exact Match) | OTP 재실행 | 계산 비용 |
|--------|------|---------------------|-----------|-----------|
| A. Pooled MSA | θ 보정 | +1.02%p (Best Match) | **필요** | ~2시간 |
| B. 유형별 θ | θ 보정 | +4.3%p (Best Match) | **필요** | ~5시간 |
| E. 확률적 RSM | θ 최적화 | +0.95%p (OTP 1순위) | **필요** | ~12시간 |
| **MNL 재순위** | **β 기반 재순위** | **+1.89%p (OTP 1순위)** | **불필요** | **~17분** |

> **주의**: 접근법 A, B는 Best Match 기준, MNL 재순위와 E는 OTP 1순위 기준이므로 직접 비교에 주의 필요. 같은 OTP 1순위 기준으로 비교하면, θ 최적화의 최대 개선폭은 +0.95%p (접근법 E), MNL 재순위는 +1.89%p로 **약 2배**.

### 8.2 θ 최적화의 구조적 상한

접근법 A, B, E를 통해 확인된 θ 최적화의 한계:

```
θ 최적화 개선 경로:
  OTP 기본값 → θ 보정 → det_exact: +0.95%p
  (generalized_cost 순위가 약간 개선)

MNL 재순위 개선 경로:
  OTP 기본값 → MNL β 적용 → mnl_exact: +1.89%p
  (행태 모형 기반으로 순위를 완전히 재정렬)

이론적 상한:
  Best Match → +8.28%p (Choice Set에 관측 경로가 포함된 경우의 상한)
```

θ 최적화가 +0.95%p에 그치는 근본 이유:
1. **OTP 비용함수의 선형성**: generalized_cost = ride + walkRel×walk + transCost×transfer는 선형 결합 → 비선형 행태 표현 불가
2. **이산적 경로 변화**: θ를 미세 조정해도 동일 경로 생성, 크게 변경하면 완전히 다른 경로 → 최적점이 존재하기 어려움
3. **MNL β의 표현력**: 4개 변수의 가중치 비율이 generalized_cost의 3개 파라미터보다 행태를 더 세밀하게 표현

## 9. 학술적 기여

### 9.1 방법론적 기여

1. **전통적 반복 보정의 한계 실증** (Section 2)
   - 대중교통의 이산적 특성으로 인해 파라미터 변경 시 경로 세트가 급변
   - 도로 네트워크 기반의 전통적 SUE 반복 보정이 대중교통에 직접 적용 불가함을 실증

2. **Choice Set 고정 보정 프레임워크** (Section 3-4)
   - β를 Ground Truth로 고정하고 θ만 MSA로 수렴하는 안정적 접근
   - 유형별 θ 적용 시 +4.3%p 개선 달성

3. **평가 지표 3단계 발전** (Section 5)
   - Best Match → OTP 1순위 → MNL 확률 가중
   - 결정론적에서 확률적 평가로의 진화 과정을 체계적으로 제시

4. **θ 최적화의 구조적 상한 발견** (Section 6)
   - 확률적 RSM(F₁ 목적함수, IPW 보정, R²=0.98)을 적용해도 OTP 1순위 기준 ~+1%p가 상한
   - 원인: F₁ 최적화의 대부분이 θ 개선이 아닌 MNL 재순위 효과에 기인

5. **MNL 재순위의 이론적·실증적 정당화** (Section 7, **핵심 기여**)
   - OTP 재실행 없이 +1.89%p 개선 (θ 최적화의 2배)
   - 불일치 시 MNL:OTP 승률 = 10.4:1 (Exact Match 기준)
   - 대안 수가 많을수록 MNL 개선폭 증가 (단조 관계)
   - 유형별·환승별·시간대별 안정적 우위

### 9.2 실무적 기여

1. **경로 추천 시스템 개선 프레임워크**
   - 기존: OTP generalized_cost 순위 → 1순위 추천
   - 제안: OTP로 대안 생성 → MNL β로 재순위 → 행태 반영된 추천
   - 추가 계산 비용 거의 없음 (17분/130만 체인)

2. **유형별 OTP 파라미터 권장값** (접근법 B)
   - GENERAL: walkRel=4.07, transCost=202
   - CHILDREN: walkRel=2.97, transCost=145
   - YOUTH: walkRel=2.71, transCost=139
   - ELDERLY: walkRel=1.75, transCost=109
   - DISABLED: walkRel=7.28, transCost=358

3. **MNL β 계수의 이중 활용**
   - 경로선택 행태 분석 (Phase 3의 원래 목적)
   - 경로 추천 순위 개선 (Phase 4의 새로운 활용)
   - → 하나의 모형으로 "분석 + 예측 + 추천"을 통합
